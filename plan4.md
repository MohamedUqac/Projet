2. Implémenter uniquement `reconnaitre` dans `code/gesture_commands.py`. L'ordre d'évaluation est la règle de sécurité et ne doit pas être modifié : (a) d'abord, parcourir TOUTES les mains et chercher une paume ouverte ; (b) ensuite seulement, si deux mains sont détectées, retourner l'avance ; (c) ensuite seulement, pour une seule main, juger si le pouce est levé puis calculer la rotation ; (d) sinon retourner `None`.
3. Paume ouverte : une main est ouverte quand `count_folded_fingers` rend `projet_cfg["gesture_open_hand_fingers"]` (zéro), en utilisant `to_pixels` puis `hand_metrics` de `thumb_detector`. Ne pas se fier à `ThumbVerdict.folded_fingers` : pour une main trop petite, `analyse_hand` rend 0 sans avoir rien mesuré, ce qui ressemblerait à tort à une paume ouverte. Une main dont l'échelle est sous `devoir1_cfg["min_hand_scale_px"]` est ignorée. Le geste retourné se nomme `paume_ouverte`, porte `urgence=True` et un `Twist(0.0, 0.0)`.
4. Avance à deux mains (aucune paume ouverte) : geste nommé `avance_deux_mains`, `urgence=False`, vitesse linéaire `projet_cfg["linear_speed"]` bornée par `projet_cfg["vitesse_lineaire_max"]`, vitesse angulaire nulle.
5. Rotation à une main : si `analyse_hand(...).is_up` est faux, retourner `None`. Sinon calculer l'angle avec `inclinaison_main` (déjà écrite) en lui passant `devoir1_cfg["min_vector_norm"]` ; si l'angle est `None`, retourner `None`. Dans la zone morte (valeur absolue de l'angle ≤ `ZONE_MORTE_DEG`), retourner `pouce_leve_neutre` avec une vitesse angulaire exactement nulle. Au-delà, retourner `pouce_leve_rotation` avec `projet_cfg["angular_gain"] * radians(angle)`, bornée à plus ou moins `projet_cfg["vitesse_angulaire_max"]`. Mettre l'inclinaison signée dans `detail`.
6. Lancer `python -m pytest test/test_gesture_commands.py -q`. Tous les tests du fichier doivent passer, y compris les signes opposés à gauche et à droite et le poing fermé qui rend `None`.
